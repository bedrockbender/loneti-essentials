# Reporting a security issue

Use **Report a vulnerability** on the [repository’s Security tab](https://github.com/bedrockbender/loneti-essentials/security) to report an issue privately. Include the userscript or Android app version, relevant browser or Android WebView version, and enough detail to reproduce it. Exclude passwords, cookies, signing keys, and private LONETI content from any attachments.

Use [Issues](https://github.com/bedrockbender/loneti-essentials/issues) for ordinary bugs and feature requests.
